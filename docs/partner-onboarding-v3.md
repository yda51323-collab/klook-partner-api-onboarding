# Klook 合作方接入说明 v3

## 1. 接入域名

| 环境 | 域名 | 用途 |
|---|---|---|
| 生产 | `https://api.klook.com/v3` | 下单、查询、退款 |
| 沙箱 | `https://sandbox-api.klook.com/v3` | 联调 |
| 回源 | `https://supplier.klook.com/callback` | 核销与状态回调 |

签名密钥在合作方后台「开发者中心 → 应用管理」处生成，应用编号形如 `klk_supplier_2041`。

## 2. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/activities` | 商品列表（分页 50） |
| POST | `/orders` | 创建订单 |
| POST | `/orders/{no}/voucher` | 核销 |
| POST | `/orders/{no}/refund` | 退款 |

## 3. 结算

结算周期为 T+7，结算款打入合作方登记的收款账户。账户变更需提交《结算账户变更单》，附开户许可证扫描件。
